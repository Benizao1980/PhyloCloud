# PhyloCloud output gallery

These figures were created by the **real PhyloCloud Python renderer** from fictional synthetic inputs, *not* by image-generation software and not from private GETcampy data.

| Cloud | Canopy |
|:---:|:---:|
| ![Native Cloud](cloud-demo.jpg) | ![Native Canopy](canopy-demo.jpg) |

The small preview JPEGs are deliberately kept in GitHub so the repository loads quickly. Complete **SVG, PDF, PNG and provenance JSON** outputs are generated by the current CLI and by the [example gallery workflow](../../.github/workflows/example-gallery.yml), which offers downloadable run artifacts. The action also renders the *synthetic E. coli* six-lineage example, producing overview and original-coordinate neighbourhood outputs.

## Reproduce all outputs on your machine

```bash
pip install -e .
phylocloud demo --outdir outputs/demo --style cloud --references 60

phylocloud plot --tree outputs/demo/synthetic_tree.nwk \
  --metadata outputs/demo/synthetic_metadata.tsv \
  --selected outputs/demo/selected_genomes.txt \
  --style canopy --out outputs/canopy

phylocloud plot --tree examples/other_pathogen/synthetic_tree.nwk \
  --metadata examples/other_pathogen/synthetic_metadata.tsv \
  --selected examples/other_pathogen/selected_genomes.txt \
  --config examples/other_pathogen/config.yml \
  --style cloud --cloud-group-by lineage \
  --detail-selected examples/other_pathogen/detail_selected.txt \
  --out outputs/synthetic_ecoli
```

All files are deterministic in scientific geometry. Some metadata and PDF rendering fields may be platform dependent; use the provenance file to audit input hashes, edge counts and length consistency.

The example E. coli tree is **fictional** and intended to verify non-Campylobacter usability, not actual strain evolution.
